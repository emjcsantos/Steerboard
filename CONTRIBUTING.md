# Contributing

Thanks for helping improve Steerboard.

## Local Setup

Follow the source-first setup in [Installation Strategy](docs/operations/installation-strategy.md). Keep setup scripts minimal and easy to inspect.

## Contribution Rules

- Keep public examples generic and free of private project names, local paths, credentials, raw transcripts, or account state.
- Keep runtime integrations behind documented adapters.
- Add tests or smoke checks for behavior changes when possible.
- Document user-facing behavior changes in the relevant product or architecture docs.
- Do not copy third-party source code, assets, or dependency graphs without a recorded license, security, and attribution review.

## Security

Report security issues privately when a private channel exists. Do not open public issues containing secrets, credentials, exploit steps against live accounts, or private user data.
