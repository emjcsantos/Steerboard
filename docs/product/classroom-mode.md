# Classroom Mode

Classroom Mode is an optional presentation for the same durable orchestrated run shown by Professional Mode. Professional remains the default. Switching presentations changes only layout and visual explanation; it does not restart, pause, cancel, delay, redispatch, or copy runtime work.

The room shows the main Orchestrator as teacher, the Validator as assistant teacher, and only real restored worker participants as students. Empty desks communicate approved capacity. Worker selection opens read-only roster and inspector context. The user always chats with the Orchestrator; there is no worker, validator, or broadcast recipient.

The initial five-place room scales to twenty collision-proven places. Status remains available as text and icon with motion disabled. Zoom, pan, fit, reset, roster navigation, high-zoom reflow, reduced motion, and forced-colors styles preserve keyboard and assistive-technology access. Bubbles are sanitized optional previews with durable fallback links. Animation is ephemeral and cannot control execution.

## Availability

Classroom availability has four explicit rollout states: off, internal preview, owner approved, and rolled back. Off and rolled back render the unchanged Professional presentation. Internal preview is for deliberate local review. Owner-approved rollout exposes the presentation switch. Disabling or rolling back Classroom does not mutate the underlying run, participant, job, message, or validation records.

See [Classroom Mode rollout](../operations/classroom-mode-rollout.md) for operator controls and verification.
